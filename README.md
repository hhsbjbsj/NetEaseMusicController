# NetEaseMusicController (Modern 强化版)

> 躺在床上用手机控制电脑上的网易云音乐，切歌、暂停、调音量、定时关机，再也不用大冷天爬起来操作电脑了！

本项目基于 [winkidney/NetEaseMusicController](https://github.com/winkidney/NetEaseMusicController) 进行现代化重构升级。

原项目基于 2015 年 Python 2.7 打包，在现代 Windows 10 / Windows 11 系统下存在底层模拟按键失效、丢键、无响应等问题。本项目全面使用 Python 3 进行重写，无需安装任何第三方库，即开即用。

---

## 🌟 核心改进与特性

1. **全面升级 Python 3 标准库**
   * 采用 Python 3 原生 `http.server` 与 `ctypes` 实现，**零第三方依赖（无需 `pip install`）**，干净绿色。
2. **彻底解决 Win10 / Win11 按键失效问题**
   * 原版采用微秒级快速触发，按键无硬件扫描码且松键顺序倒置，现代 Windows 会直接当成无效按键丢弃。
   * 本项目重构了按键模拟引擎：**严格还原人类按键的物理延时与正确的松开顺序，并自动映射硬件扫描码（Hardware Scan Code）**，完美触发网易云全局热键。
3. **双通道控制保障**
   * 每次触发时，除了模拟快捷键（`Ctrl + F1~F6`），还会**同步发送 Windows 原生多媒体按键**（`VK_MEDIA_NEXT_TRACK` 等）。即使快捷键有轻微冲突，多媒体键也能 100% 确保切歌成功！
4. **智能局域网 IP 识别**
   * 服务启动时自动检测当前本机的局域网 IPv4 地址并直接打印出访问链接，无需手动执行 `ipconfig` 查询。
5. **双端无缝支持**
   * 📱 **手机浏览器直接控制**：打开自带浏览器输入局域网地址即可使用漂亮的 Web 控制面板。
   * 📲 **手机专用 APP 控制**：完全兼容原版 React Native Android APP 接口（`/mobile_connect`）。

## 🚀 快速上手

### 1. 配置电脑端「网易云音乐」客户端
打开网易云音乐客户端，进入右上角 **设置** $\rightarrow$ **快捷键**：
1. 勾选 **「启用全局快捷键」**。
2. 确认或设置以下对应快捷键：
   * **上一首**：`Ctrl + F1`
   * **播放 / 暂停**：`Ctrl + F2`
   * **下一首**：`Ctrl + F3`
   * **音量减**：`Ctrl + F4`
   * **音量加**：`Ctrl + F6`
   *(注：关机操作为系统底层指令，无需设置快捷键)*

### 2. 启动服务端
确保电脑安装了 Python 3（Windows 10/11 通常已自带或通过应用商店/官网安装）。

双击项目根目录下的 **`启动网易云遥控器.bat`**：
```text
============================================================
  网易云音乐遥控器（强化版）已成功启动！
  电脑本机IP地址 : 192.168.1.6
  服务监听端口   : 10010
------------------------------------------------------------
  手机浏览器访问 : http://192.168.1.6:10010
  手机 APP 填写  : 192.168.1.6:10010
============================================================
```

### 3. 手机端控制

> ⚠️ **前提条件**：手机和电脑需连接在同一个家庭 WiFi / 局域网下。

#### 方式一：手机浏览器访问（最推荐，免安装）
手机浏览器直接在地址栏输入控制台打印的地址，例如：
```text
http://192.168.1.6:10010
```
即可在网页上直接点击切换上一首、下一首、暂停/播放、调音量或关机。

#### 方式二：使用配套 Android APP
1. 打开配套 APP。
2. 在地址栏填入：`你的电脑IP:10010`（例如 `192.168.1.6:10010`，**注意切勿带 `http://`**）。
3. 点击「设置服务器」，连接成功后即可遥控。
