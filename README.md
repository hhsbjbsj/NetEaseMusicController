# NetEaseMusicController (Modern 旗舰版 v2.5)

> 躺在床上用手机控制电脑上的网易云音乐：切歌、暂停、调音量、单曲循环、随机播放、顺序播放、收藏红心、定时关机，再也不用大冷天爬起来操作电脑了！

本项目基于 [winkidney/NetEaseMusicController](https://github.com/winkidney/NetEaseMusicController) 进行现代化重构升级，彻底解决 2015 年原版在现代 Windows 10 / Windows 11 下按键失效的问题，并全新重构了手机端体验与现代化 Android App 工程。

---

## 🌟 核心特性与重大升级

1. **全面升级 Python 3 原生标准库**
   * 采用 Python 3 原生 `http.server` 与 `ctypes` 实现，**零第三方依赖（无需 `pip install`）**，干净便携。
2. **彻底修复 Win10 / Win11 按键失效**
   * 原版按键无硬件扫描码且微秒级释放导致现代 Windows 拦截。
   * 本项目重构按键引擎：**严格还原人类物理按键延时与释放顺序，并自动映射硬件扫描码（Hardware Scan Code）**，完美触发网易云全局热键。
3. **双通道控制保障**
   * 每次触发时，除了模拟快捷键，还会**同步发送 Windows 原生多媒体按键**（`VK_MEDIA_NEXT_TRACK` 等），双重保险！
4. **🎵 实时曲目追踪 (Now Playing)**
   * 手机端实时读取并显示电脑网易云正在播放的**歌曲名称与歌手**，配有动态跳动声波指示器。
5. **🔁 全套播放模式支持**
   * **🔂 单曲循环**：内置智能单曲循环助手，自动重播当前歌曲。
   * **🔁 列表循环**：标准循环播放整个歌单。
   * **🔀 随机播放**：随心听歌体验。
   * **➡️ 顺序播放**：按顺序播放列表歌曲。
   * **🔄 本首从头重播**：无论播到哪，一键回滚到 0:00 从头再听一遍。
6. **❤️ 喜欢/收藏红心音乐**
   * 躺在床上听到好歌，手机上点一下即可一键加入“我喜欢的音乐”。
7. **🌙 睡眠定时关机**
   * 睡前听歌必备：支持设置 15 / 30 / 45 / 60 分钟后电脑自动关机，支持一键取消或立即关机。
8. **📲 现代化移动端方案（双端自由选）**
   * **方案 A：PWA 原生级 Web App（免安装）**：手机浏览器打开，点击“添加到主屏幕”，秒变独立全屏原生体验 App。
   * **方案 B：现代 Android App 安装包（.apk）**：内置全新 Android 工程，支持自动记忆电脑 IP，并通过 GitHub Actions 自动云端打包生成 APK。

## 🚀 快速上手

### 1. 配置电脑端「网易云音乐」客户端
打开网易云音乐客户端，进入右上角 **设置** $\rightarrow$ **快捷键**：
1. 勾选 **「启用全局快捷键」**。
2. 确认或设置以下对应快捷键：
   * **上一首**：`Ctrl + F1`
   * **播放 / 暂停**：`Ctrl + F2`
   * **下一首**：`Ctrl + F3`
   * **音量减**：`Ctrl + F4`
   * **音量加**：`Ctrl + F6`
   * **喜欢音乐**：`Ctrl + Alt + L`（默认快捷键）
   *(注：单曲循环、播放模式与关机由服务端直接调度，无需额外快捷键)*

### 2. 启动服务端
双击项目根目录下的 **`启动网易云遥控器.bat`**：
```text
================================================================
  网易云音乐遥控器（Modern v2.5 全功能旗舰版）已启动！
  电脑本机IP地址 : 192.168.1.6
  服务监听端口   : 10010
----------------------------------------------------------------
  手机浏览器访问 : http://192.168.1.6:10010
  手机 APP 填写  : 192.168.1.6:10010
================================================================
```

### 3. 手机端控制

> ⚠️ **前提条件**：手机和电脑连接在同一个家庭 WiFi / 局域网下。

#### 方式一：手机浏览器直接访问（最简单，免安装）
手机浏览器打开终端显示的网址（如 `http://192.168.1.6:10010`），点击右上角菜单选择 **「添加到主屏幕」**，即可生成独立全屏图标！

#### 方式二：下载全新 Android APP 安装包
前往本项目 GitHub 仓库的 **[Releases](https://github.com/hhsbjbsj/NetEaseMusicController/releases)** 页面，下载最新的 `NetEaseController-v2.5.apk` 安装即可。
